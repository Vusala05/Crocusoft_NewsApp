# News Catcher

A modern News application that provides a seamless reading experience with multi-language support and offline capabilities.

## Tech Stack
* **Language:** Kotlin
* **UI:** Jetpack Compose
* **Architecture:** MVI + Clean Architecture
* **Local Database:** Room
* **Preferences:** Jetpack DataStore
* **Localization:** Multi-Language Support (LocaleManager & Dynamic switching)
* **Networking:** Retrofit & OkHttp
* **DI:** Hilt
* **Async:** Coroutines & Flow
* **Image Loading:** Coil
